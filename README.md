Shaxsiy portfolio sayti — mening ish tajribam, ko‘nikmalarim va loyihalarim jamlangan professional veb-platforma. Sayt zamonaviy dizayn, yuqori tezlik va barcha qurilmalarga moslashuvchan (responsive) ko‘rinishda yaratilgan.

## 🧑‍💻 Saytdan foydalanish

Saytda quyidagi bo‘limlar mavjud:

### **1️⃣ Bosh sahifa**
- Men haqimda qisqa tanishuv  
- Mening maqsadlarim va yo‘nalishim  
- Asosiy rasmlar va animatsiyalar  

### **2️⃣ Ko‘nikmalar (Skills)**
Bu bo‘limda mening Frontend bo‘yicha bilgan texnologiyalarim ro‘yxati mavjud:

- HTML5 / CSS3  
- JavaScript (ES6+)  
- Bootstrap  
- Sass / Less  
- Responsive Design  
- Git / GitHub  
- Figma va boshqalar  

### **3️⃣ Loyihalar (Projects)**
Bu yerda:
- Real ishlagan loyihalarim,
- Demo linklar,
- Kodlar (agar mavjud bo‘lsa),
- Screenshotlar joylashgan.

### **4️⃣ Men haqimda (About)**
- Tajribam  
- Qobiliyatim  
- Ish jarayoniga yondashuvim  

### **5️⃣ Aloqa (Contact)**
Sayt orqali menga murojaat yo‘llashingiz mumkin:  
- Email formasi  
- To‘g‘ridan-to‘g‘ri Email yuborish tugmasi
